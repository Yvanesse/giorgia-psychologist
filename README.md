# Giorgia Petruzzellis

Sito web professionale di Giorgia Petruzzellis, realizzato con Next.js, TypeScript e Tailwind CSS.

## Sviluppo

```bash
npm install
npm run dev
```

Apri [http://localhost:3000](http://localhost:3000) nel browser.

## Verifiche

```bash
npm run lint
npm run typecheck
npm run build
```
